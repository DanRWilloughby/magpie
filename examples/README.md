# Example library

This is a real Magpie library you can poke through — the exact folder shape the skill writes, populated so every file has something in it.

**Real:** the two notes under `notes/` are genuine captures — both videos were run through the actual capture engine, and the beats, claims, and timestamps check against the sources (receipts in `log.md`).
**Illustrative:** `profile.md` describes a generic example owner, and `rivals/example-competitor.md` documents a *fictional* company — it exists to show the living-dossier-with-diffs shape.
`raw/` holds short transcript excerpts only: full transcripts stay in your own library; this repo keeps examples small and copyright-clean.

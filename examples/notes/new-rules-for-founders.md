## Top signal

1. **The skillify-everything operating doctrine (t=23:40–26:22).** Do any business process once perfectly with an agent, freeze it as markdown + code + tests on a cron, and treat every later failure as a permanent bug fix — "a markdown file is an employee." This is YC's president describing, as the mainstream founder playbook, an architecture any solo builder can start running today.
2. **Markdown-memory needs provenance + conflict management + accuracy-sweep crons (t=26:41–27:21).** Garry names the three failure modes of agent memory at scale before most builders have hit them. If you keep any durable markdown corpus, this is the maintenance roadmap: tag where facts came from, decide which of two conflicting facts wins, and sweep for staleness on a schedule.
3. **"Harness wars in 2027," gated purely on token cost (t=42:49–43:22).** Frontier price → $50–100 in 2–3 years reopens a browser-wars-scale consumer fight; per-seat SaaS is simultaneously called a dead-end wedge (t=15:35). Together these are a timing thesis: build distribution and memory moats before the cost collapse, not after.

## Lens: Learn — 2026-08-16

What changes how you'd act, beyond the claims above:

- **Skillify as a habit, not a project (t=23:40–24:50).** The loop is concrete enough to adopt tomorrow: do a task once with an agent, freeze the working version as markdown + code + tests, schedule it, treat every later failure as a permanent bug fix. The compounding comes from the freezing step most people skip.
- **Budget for memory hygiene early (t=26:41).** Once a markdown corpus grows, you need provenance tags, a rule for which of two conflicting facts wins, and a periodic accuracy sweep. Cheaper to add at file 10 than at file 1,000.
- **Handle the $15M-ARR datapoint carefully (t=26:08).** It's unnamed and secondhand — usable only as "Garry Tan claims," never as fact.
- **If you sell software, stress-test your pricing against t=15:35.** Per-seat is called a wedge, not an endgame; the leap is to data/network moats. Even if you disagree, know your answer.
- **A reusable craft atom (t=17:56):** when releasing an internal high-intensity prompt or playbook publicly, dial the intensity down as an explicit separate pass ("reduce the strength by 90%") rather than rewriting from scratch.
- **The timing frame (t=42:49–43:22):** frontier token price stays premium while trailing-frontier falls toward zero. If that holds, context and memory assets built now sit under the cost collapse rather than arriving after it.
